# Integration contract
All packages are ESM TypeScript in a pnpm workspace. Internal imports use @rr/domain, @rr/solver, @rr/qloo, @rr/shared. Package exports point to src/index.ts; API runs with tsx; web Vite bundles source. Strict TS. Root handles scaffolding.
Domain owner writes packages/domain and packages/solver plus data fixtures, tests solver. Domain types and demo factory exported from @rr/domain. Coordinate exact schema with other workers immediately. Money integer pence (currency GBP); ISO UTC dates; fixed dated slots in 2026 with nonoverlap and enough runtime. Demo synthetic rights AND synthetic affinities clearly marked, never Qloo recorded evidence. Exactly 30 films, 3 cohorts,4 slots.
API state contract exposed GET /api/state: {cinema, films, cohorts, slots, constraints, versions, events, runs, affinities, evidenceMode, providerStatus}. POST /api/demo/reset. POST /api/programmes/generate body {mode?:'DEMO'|'QLOO'|'METADATA'|'LLM_ONLY'}. POST /api/programmes/:id/approve body {versionId}. POST /api/events body discriminated ChangeEvent request. API responds full state for mutation convenience. Detailed additional endpoints per plan.
Frontend/API workers coordinate their shared state schema directly. API supplies version snapshots with items, coverage, objective, totalCost, evidence and status. Missing affinity is null/absent, never zero. Rank normalization on same fixed candidate universe; partial results block QLOO solve by default. Film mapping resolution requires confirmation when ambiguous. Qloo raw evidence separate from synthetic and metadata.
All workers own their scope only. No publication, external rights enquiries, credential setup, or secret files. README tells live feasibility gate unverified without API key. Run modest targeted checks, not exhaustive suites. Return files, actual tests/results, remaining limitations.
